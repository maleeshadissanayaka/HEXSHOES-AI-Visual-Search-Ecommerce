- License: [Pexels license](https://www.pexels.com/license/), checked 8 October 2026.
- Source download: https://videos.pexels.com/video-files/8520623/8520623-uhd_4096_1680_25fps.mp4
- Local derivative: first 12 seconds, 1280 px wide, H.264, CRF 25, no audio,
  MP4 faststart, approximately 1.3 MB. The 34 MB source was removed after encoding.
- Existing campaign WebP remains the poster/error fallback.
- Autoplay is muted and limited to desktop without reduced-motion preference.
  Mobile/reduced-motion viewers receive a static hero. Explicit Watch Film opens
  the video with native playback controls and no automatic playback.
- Decorative playback pauses offscreen or when the document becomes hidden.

Encoding used a temporary FFmpeg utility under ignored test artifacts. No
runtime dependency or package manifest was changed.
